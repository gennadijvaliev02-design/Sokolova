SOKOLOVA massage studio — demo by BUONA FORTUNA

Файлы:
- index.html — сайт
- assets/ — исходные изображения и производные before/after

Запуск:
Откройте index.html в браузере или загрузите папку целиком на GitHub Pages.

Что реализовано:
- адаптивный premium layout
- крупный hero с фото
- фирменные line-art SVG элементы
- мастера
- интерактивные до/после слайдеры
- прайс с вкладками
- пробный прайс
- 4-шаговая демо-запись
- отправка выбранной записи в WhatsApp

Примечание:
Демо-запись использует пример свободных дат/времени. В полноценной версии расписание подключается к реальной системе записи.
